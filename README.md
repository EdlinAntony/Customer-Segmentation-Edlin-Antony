# Customer Segmentation using K-Means Clustering

## 📖 Project Overview
This project utilizes unsupervised machine learning to group customers (or students) into distinct segments based on their behavioral scores. It applies the **K-Means Clustering** algorithm and uses the **Elbow Method** to determine the optimal number of clusters.

## 🎯 Objective
To help businesses understand their customer base better, allowing for targeted marketing strategies, personalized services, and improved resource allocation.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn (KMeans), Matplotlib
- **Algorithm:** K-Means Clustering

## 📊 Dataset
The model analyzes numerical score data:
- **Math Score:** Performance in mathematics
- **Science Score:** Performance in science
*(Note: These scores act as proxies for customer spending and engagement metrics).*
